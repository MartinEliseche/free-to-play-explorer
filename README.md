# 🎮 Free-to-Play Explorer

¡Bienvenido! Este es un proyecto personal "chill" que desarrollé para explorar el consumo de APIs externas y la manipulación dinámica del DOM utilizando JavaScript Vanilla. La idea es simple: navegar a través de una biblioteca de juegos gratuitos y ver sus especificaciones técnicas.

## 🚀 Características
- **Listado Dinámico:** Renderizado de juegos mediante la API de [FreeToGame](https://www.freetogame.com/api-doc).
- **Sistema de Detalle:** Navegación hacia una vista dedicada por juego mediante parámetros en la URL.
- **Dark Mode UI:** Interfaz moderna y minimalista diseñada con CSS Grid y Flexbox.
- **POO:** Uso de Clases en JavaScript para el modelado de datos de los videojuegos.

## 🛠️ Tecnologías
- **HTML5** & **CSS3** (Custom Properties & Grid Layout)
- **JavaScript (ES6+)** - Módulos, Async/Await y Fetch API
- **Google Fonts** (Inter)
